本版基于 OpenIDEA 0.1.37，加入低资源模式和提交信息生成插件。

## 低资源模式

在 **File → Power Save Mode（省电模式）** 开启。语言服务器、项目符号索引和自动检查远端提交会暂停；编辑、Git、文件名检索和全文搜索仍可使用。关闭该模式后恢复代码分析。

在 4,080 文件的独立索引进程中，3 次 Debug 构建测量的工作集内存中位数从 45.3 MiB 降至 11.8 MiB，累计 CPU 时间从 17.84 秒降至 0.17 秒。这不是整个 IDE 的占用降幅，原始样本与复测脚本见仓库说明。

## 提交信息生成

下载附件 `finalpi.commit-assistant-0.1.0.oiplugin`，在 **Settings → Plugins → Install Plugin from Disk** 安装。

- 支持自填 OpenAI 兼容接口地址、模型和 API Key。
- 先暂存改动，再点击提交信息栏的生成按钮；可选择 AI 或离线生成。
- 仅在点击时执行，结果填入可编辑草稿，不会自动提交或推送，也不启动常驻本地模型。
- Key 使用 IDE 的密钥存储。AI 功能需授予网络和密钥权限；离线功能不请求 API。

## 下载说明

安装包覆盖 Windows、macOS、Linux 的 x64 / ARM64。远程开发服务端与插件附件提供 SHA-256 校验文件。

本次构建没有配置系统代码签名或 Apple 公证，也不生成签名自动更新清单；请下载 Release 附件手动安装。应用与远程服务的下载地址已指向本 fork。

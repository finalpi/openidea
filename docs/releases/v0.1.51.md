本版合并上游 OpenIDEA v0.1.49 及后续修复，纳入大项目索引和 Git 日志的内存优化，以及语言服务、编辑器和设置界面的修复。fork 的省资源模式继续支持仅索引文件名，关闭后恢复完整索引。

Wasmtime 更新到 49.0.7，包含 Windows 插件沙箱的安全修复。[官方安全公告](https://github.com/bytecodealliance/wasmtime/security/advisories/GHSA-f2pq-268w-886c)

- **Commit Assistant 0.2.1** 保留模型下拉、API 测试、提示词与提交栏的“生成描述”按钮，支持勾选的未暂存改动。新版使用上游的按域名授权机制。升级插件后，在插件详情页开启网络权限，首次连接 API 时确认域名。
- **Maven** 工具窗口顶部仍有“跳过测试”复选框。勾选后，`package` 会带上 `-DskipTests`。

请先更新桌面版，再在「设置 → 插件 → 从磁盘安装」选择附件 `finalpi.commit-assistant-0.2.1.oiplugin`。桌面安装包覆盖 Windows、macOS、Linux 的 x64 和 ARM64。未配置签名密钥时，请从本页手动更新。

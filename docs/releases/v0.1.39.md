本版改进 Commit Assistant 的配置和生成流程，并把 Maven 的跳过测试选项改为可见的文字开关。

## 升级方式

请先安装桌面版 **v0.1.39**，再从 Settings → Plugins → Install Plugin from Disk 导入附件 **finalpi.commit-assistant-0.2.0.oiplugin**。两个组件需要一起更新。直接覆盖安装插件即可，不需要先卸载，原有插件 ID 不变。

## API 配置与测试

- API Key 入口已放到 Commit Assistant 设置页。Key 在项目间共用，点击 Save 后立即保存；其他配置点击 Apply / OK 保存。
- 点击 Refresh models 读取所配置接口的模型列表，可搜索并下拉选择，也能手动填写模型 ID。
- Test API connection 读取模型列表；Test selected model 发送一条简短的测试提示，检查实际对话权限。两者都使用页面当前值，不必先点 Apply，且不发送项目代码。
- 显示 HTTP 状态及耗时，区分鉴权、权限、接口不存在、限流、超时、DNS 和 TLS 等问题。错误面板不回显服务端原始正文。
- 不提供模型列表的服务可手动填写模型，再测试所选模型。支持需要 max_completion_tokens 的兼容接口。

## 提示词与生成入口

默认提示词已在设置页完整显示，可编辑、恢复默认，并预览语言占位符展开后的内容。默认模板源文件见仓库 `plugins/official/commit-assistant/default-prompt.txt`。

提交信息栏新增 **Generate message（生成描述）** 文字按钮。默认读取当前勾选改动，包含未跟踪文件及编辑器里未保存的文本，无需先加入暂存区；右侧菜单保留离线生成和只读 Git 暂存区的选项。部分改动块的排除选择也会保留。

生成仅填入草稿，不自动保存文件、暂存、提交或推送。常见敏感文件名会过滤，二进制和大文件不发送文件内容，符号链接不读取被指向文件的内容。配置页可调整上下文、输出 Token 和超时上限，空闲时不轮询 API。

另修正了设置页面过滤插件配置的问题，保存后的接口地址和模型可正常回读。

## Maven package 跳过测试

Maven 工具窗口已有 Skip Tests 模式，本版将其显示为工具栏下方的文字勾选项。勾选后执行 package 会带上 `-DskipTests`，选项按项目保存；手动指定的同名参数优先。此参数跳过测试执行，通常仍会编译测试代码。

## 下载

附件覆盖 Windows、macOS、Linux 的 x64 / ARM64，包含远程服务端、插件及 SHA-256 校验文件。本次仍采用未配置证书签名和 Apple 公证的构建，安装包请手动下载更新。
